DEPLOYMENT GUIDE

Get Started in 60 Seconds

Run the trading agent locally on Linux, macOS, or Windows.

1

Download the source code and install the required Solana & web3 libraries.

git clone https://github.com/yashab-cyber/pumpfun.git && cd pumpfun && npm i
2

Build TypeScript Binaries

Compile TypeScript into production artifacts and copy public UI assets.

npm run build
3

Launch Paper or Live Mode

Run zero-risk simulation or start autonomous on-chain execution.

npm run paper
